Whats JavaScript?

JavaScript is basically Java but easier.

The code in java might look like this:

import javax.swing.JOptionPane; public class Main { public static void main(String[] args) { // Displays a pop-up dialog box with the message "Hello" JOptionPane.showMessageDialog(null, "Hello"); } }

While the code in JavaScript might only look like this:

alert("Hi")

Java is hard, while JavaScript is easy for beginners.
