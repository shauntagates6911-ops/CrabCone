# Start.md
This is the guide of how to create a custom extension or block in CrabCone.

# 1. Click a choice
you can either click Create a block, or you can create a [extension](https://crabcone.js.org/new.html).
you can pick one that you like, but generally extensions are better.

# 2. Creating extensions
A extension is basically scratch’s way of saying power-up. It adds extra blocks to your code and allows you to make projects that can access the Makey Makey to make everything a key, for example.
A extension can also be used for specific purposes like creating possibilities, or answering questions, it all can do anything you like!


Want to start creating? go to index.html for more guides!
